# AI行为调查局

《AI行为调查局》是一款把 AI Agent 工程知识转译成调查解谜体验的网页游戏。玩家不会先看到概念讲解，而是通过观察现场、询问角色、收集证物和连接因果，亲手查明一套系统为什么失败；只有结案后，游戏才揭示对应的正式工程知识。

## 故事背景

一座近未来城市将交通、档案、水务、工坊和应急调度接入“回声网络”。暴雨逼近北岸时，城市仪表仍不断报告正常，现实却开始与报告分离。

玩家作为 AI行为调查局的行为勘验员，需要重建命令进入系统后发生的一切，并遵守调查局的第一守则：

> 让现实，而不是口供，决定是否结案。

四起案件属于同一场“回声网络失序事件”，前案留下的实体、编号和记录会成为后案继续追查的线索。

## 核心玩法

观察场景 → 选择调查点 → 与角色交谈 → 收集证物 → 连接因果 → 操作最终机关 → 揭示术语 → 收入回声档案。

- 案件过程只呈现现象、人物立场和客观证据。
- 正式术语集中在结案揭示与知识卡中。
- 每案独立保存调查进度，也可以按编号连续游玩。
- 已结案件会收入“回声档案”，供玩家回顾知识关系。
- 桌面端和移动端均可完成调查，不依赖拖拽操作。

## 设计理念

- 先现象，后术语。
- 知识必须成为谜题解法，而不是附加说明。
- 环境证据优于角色自述，现实终态优于系统的成功回执。
- 故障来自模型、上下文、工具、环境和 Harness 的组合关系，而不是简单归因于“AI 失控”。
- 每案只承担一个核心认知冲突，并为下一案留下可追踪证据。

## 技术与素材

项目使用原生 HTML、CSS 和 JavaScript 构建，调查进度保存在浏览器本地。游戏环境与人物图像位于 `image/`，由 OpenAI 内置图像生成工具生成；关键线索文字由网页界面呈现。
